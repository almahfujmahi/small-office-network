Small Office Network By Mahi
A small office network designed and simulated using Cisco Packet Tracer

Network Topology
2 PCs
1 Cisco 2960 Switch
 Copper Straight-Through cables

IP Addressing-
Device - PC-PT0 - IP- 192.168.1.10 AND SUBNET MASK - 255.255.255.0 
Device -  PC-PT1 - IP- 192.168.1.20 AND SUBNET MASK - 255.255.255.0 

Connectivity Test

The connectivity between PC-PT0 and PC-PT1 was tested using the `ping` command.

Result: **0% packet loss**
